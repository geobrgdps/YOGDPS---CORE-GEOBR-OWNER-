YOGDPS Core

Guia central da plataforma para criação e gerenciamento de Geometry Dash Private Servers.

Arquitetura

Frontend modular, camada de API e serviços de dados separados. O projeto foi pensado para permitir que o banco seja conectado sem acoplar a interface à infraestrutura.

Browser → YOGDPS Web → API → Data Layer → GDPS

GDPS API

A camada de API terá endpoints compatíveis com as operações necessárias do Geometry Dash, incluindo autenticação, níveis, usuários e dados do servidor.

Supabase

O Core não contém credenciais nem configuração do Supabase. O projeto será conectado ao seu workspace Supabase quando o schema e as políticas forem preparados.

Segurança

Autenticação, autorização por projeto, RLS, validação de entrada, rate limiting e proteção de segredos devem ficar no backend. Nunca coloque chaves privadas no frontend.
